Сформировано руководство пользователя по работе с приложением: 
1. Запуск с рабочим файлом: запустите приложение, передав первым параметром командной строки путь к файлу work-data.json (при запуске без аргументов используется data.json из каталога программы).
2. Вход и исправление логина после отказа: введите зарегистрированный логин (client или buyer) в поле «Логин:» и нажмите «Войти». При вводе неверного логина и появлении окна «Логин не найден» нажмите «ОК», исправьте логин в поле ввода и повторите нажатие «Войти».
3. Совместный поиск, категория и сортировка: после входа введите ключевое слово в поле «Поиск:» (поиск выполняется по названию и описанию без учёта регистра), выберите категорию в списке и задайте порядок сортировки («Цена по возрастанию» или «Цена по убыванию»).
4. Переход в карточку и возврат: нажмите кнопку «Открыть позицию» в строке нужного оборудования для просмотра характеристик и остатков по исполнениям. Чтобы вернуться в каталог без потери набранных строк заявки, нажмите «Назад к каталогу».
5. Добавление позиции и исправление количества: в карточке выберите исполнение («Проводной» или «Беспроводной»), укажите целое положительное число в поле «Количество:» и нажмите «Добавить в заявку». При превышении остатка появится предупреждение — уменьшите число в поле ввода и нажмите «Добавить в заявку» повторно.
6. Отмена, подтверждение и повторный запуск: для сброса неподтверждённой заявки нажмите «Отменить заявку» и подтвердите действие. Для оформления заказа нажмите «Подтвердить заявку» в карточке позиции — данные сохранятся в work-data.json, остатки обновятся и будут доступны при следующих запусках программы.
